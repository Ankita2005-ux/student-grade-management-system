# Student Grade Management System 🎓

A simple Python-based Student Grade Management System that calculates
students' total marks, percentage, and grade.

## Features

- Add student details
- Enter subject marks
- Calculate total marks
- Calculate percentage
- Assign grades
- Display student results

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python grade_manager.py
